# Cloud Penetration Testing

A cloud security assessment skill covering AWS, Microsoft Azure, and Google Cloud environments.

## Assessment areas

- Cloud reconnaissance and asset discovery.
- Identity, authentication, and access-control assessment.
- Resource and permission enumeration.
- Misconfiguration and privilege-escalation analysis.
- Exposure and secret-management review.
- Findings documentation, risk ratings, and remediation guidance.

## Usage and authorization

Use this skill only for environments you own or are explicitly authorized to assess. Establish written permission, target scope, rules of engagement, test accounts, permitted techniques, and data-handling requirements before testing.

The skill includes commands and techniques that can affect accounts, services, and data. Do not run destructive actions, persistence techniques, credential extraction, or production-impacting tests without explicit authorization and safeguards. Prefer non-invasive validation and document evidence securely.
